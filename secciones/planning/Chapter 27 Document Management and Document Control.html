Este capítulo diferencia claramente entre document management y document control dentro de un proyecto minero. Ambos tratan con documentos, pero cumplen funciones distintas: uno gestiona el almacenamiento y recuperación; el otro gobierna el ciclo de vida, versiones y trazabilidad de los documentos esenciales del proyecto.

Idea clave

En proyectos de varios años y con alta rotación de personas, la única forma de proteger los intereses del Owner es tener, desde el inicio, un sistema robusto de manejo y control de documentos. Sin sistema, la memoria del proyecto se pierde.

¿Document Management es lo mismo que Document Control?

Diferencias básicas

Aunque ambos conceptos se confunden, no son equivalentes:

  • Document Management se enfoca en almacenamiento, indexación, búsqueda, acceso y archivo de documentos (particularmente los de vida corta: correos, cartas, minutas, formularios).
  • Document Control se enfoca en controlar el ciclo de vida de documentos esenciales y multiversión (planos, especificaciones, POs, contratos), asegurando que solo la versión vigente se use en el proyecto.

En la práctica, todos los proyectos requieren un sistema de document control; la mayoría, además, necesitan un sistema de document management separado.

Document Management

Definición

Un document management system (DMS) es el sistema de almacenamiento y recuperación electrónica de documentos. Gestiona el escaneo, digitalización, indexación, búsqueda, versiones simples, archivo y eliminación de documentos a lo largo del proyecto.

Elementos deseables de un DMS

  • Capacidad para manejar cientos de documentos diarios en múltiples formatos.
  • Digitalización de todos los tipos de documentos del proyecto (ingeniería, AFEs, POs, facturas, contratos, registros de permisos, etc.).
  • Acceso robusto vía Internet e Internet portal seguro.
  • Capacidad de trabajar sobre múltiples servidores y software.
  • Gestión de versiones para documentos de una sola versión activa.
  • Distribución mediante enlaces protegidos por contraseña.
  • Motor de búsqueda por palabras clave y campos de índice.
  • Visualización de archivos con texto completo recuperable.

Beneficios de un DMS

  • Elimina la pérdida de documentos; todo se almacena e indexa en un repositorio central.
  • Reduce drásticamente el tiempo de búsqueda y recuperación.
  • Convierte documentos en papel a versiones electrónicas fáciles de compartir.
  • Mejora la colaboración y comunicación entre equipos dispersos.
  • Facilita la recopilación y consolidación de registros para operación a largo plazo (as-built, manuales, garantías, etc.).

Document Control

Definición

El document control system gobierna el ciclo de vida de los documentos esenciales del proyecto. Su función central es el version control: asegurar que solo la versión correcta y vigente esté disponible para ingeniería, compras, construcción y operación.

Elementos de un sistema de Document Control

  • Flujo controlado de documentos entre Owner, EPCM, contratistas y proveedores.
  • Seguimiento de cada documento desde su emisión hasta el as-built final.
  • Archivo de registros originales como parte de QA/QC; solo copias se distribuyen a usuarios.
  • Archivo de toda la correspondencia (cartas, emails, minutas) en formato recuperable.
  • Uso exclusivo de formatos estándar de planos y reglas de layering en CAD.
  • Sistema de numeración de planos que impide duplicados.
  • Gestión explícita de documentos obsoletos para impedir su uso y mantener trazabilidad.
  • Rastreo de vendor data y manuales mediante número de PO y códigos VDR.
  • Soporte directo a las funciones de calidad y cumplimiento regulatorio del proyecto.

Beneficios de un sistema de Document Control

  • Asegura que todos trabajen siempre con la última versión aprobada.
  • Genera una auditoría completa de cambios, fechas y responsables.
  • Aporta un nivel de seguridad y control alineado con requisitos regulatorios.
  • Centraliza el almacenamiento electrónico según jerarquía organizacional y tipo de documento.
  • Habilita acceso web controlado y consistente a documentos y flujos.

Combinando Document Management y Document Control

Estrategia recomendada

Todo proyecto debe contar con un sistema formal de document control. Para la mayoría de proyectos grandes, se recomienda complementar con un DMS que absorba el alto volumen de documentos de vida corta. En proyectos pequeños, es posible que el sistema de document control absorba también el rol de management, pero solo si el flujo de documentos transitorios es limitado.

La recomendación general del libro es usar ambos sistemas, porque pocos sistemas comerciales pueden cubrir simultáneamente la prescripción de control y la flexibilidad de manejo masivo de datos.

Flujo de Document Management y Document Control

Flowchart 27.1 – Document Management and Document Control

El flujo integra la gestión de documentos dentro de la preparación del Project Execution Plan y de la organización de proyecto. Muestra cómo las decisiones de sistemas, procesos y protocolos de control se conectan con el kickoff de proyecto.

Puntos clave del flujo

  • Se parte del Set Up Project y la designación de la Project Team Organization.
  • Durante el desarrollo de la estrategia y la planificación se finaliza el Project Execution Plan y se definen responsabilidades y autoridad.
  • Se decide qué sistemas utilizar (Owner, EPCM o nuevos) para document management y document control.
  • Se establecen document management y document control como procesos formales, antes del Project Kickoff.
